## 0. 核心结论（先回答用户问题）

**「移除一级菜单入口但保留 bazi 详情页，审核会不会查到？」**

| 审核层 | 机制 | 移除入口后是否安全 |
|---|---|---|
| 人工操作 | 审核员实际打开小程序点选，只看首页 + 可达入口 | ✅ 安全，人工点不到 bazi |
| 机器扫描 | 微信对代码包做文本/关键词扫描 | ⚠️ **不安全**：bazi.wxml 的「旺衰/喜用/忌神/大运/算命」等词仍在包内，会被机审命中 |

**结论：只移除入口不够，敏感词文本必须一起脱敏。** 这是本计划第一阶段与之前清单的差异点——即使页面隐藏，代码包内的敏感词也要改掉（或把 bazi 页从 `app.json` 的 `pages` 里移除，让代码包彻底不含该页）。

## 3. 第二阶段：wanji-agent 智能体自动排盘（免点击）

### 3.1 目标

用户**不再需要点击技能按钮**。智能体根据上下文自动判断：

- 用户提到**具体时间**（如「明天下午3点」）→ 生成奇门转盘参数
- 用户提到**生日**（如「我1990年5月生」）→ 生成八字排盘参数
- 用户提到**证券代码/名称** → 走证券投资分析
- 未提时间 → 默认用**当前时刻**起盘

### 3.2 处理流程（伪代码）

```
用户在对话中输入一句话 text:

intent = classify(text)   # 证券 / 时间盘 / 生日盘 / 通用
params = {}

if intent == '证券':
    params.stock = extract_code_name(text)          # 代码/名称
elif intent == '时间盘':
    params.qimen_time = parse_time(text) or now()   # 奇门转盘时间
elif intent == '生日盘':
    params.birth = parse_birth(text)                # 生日 → 八字
else:
    params.qimen_time = now()                       # 默认当前时空起盘（对齐现有双盘兜底）

# 自动排盘（复用 yishu.js / paipan.js 的算法）
pan = auto_pan(params)          # { qimen?, bazi? }

# 组装 Pro Deep 深度解读请求
prompt = build_deep_prompt(pan, text)
prompt += "\n输出要求：客观陈述传统历法/古籍信息，不下吉凶宜忌结论，"
prompt += "不承诺任何预测效果，末尾附'文化交流，仅供参考'免责声明。"

result = pro_deep_api(prompt)   # 脱敏大白话
reply_user(result)
```

### 3.3 关键约束

- **不点击技能，智能体自动排盘**，参数生成在服务端完成，前端仅展示结果。
- **输出脱敏**：Pro Deep 返回的大白话不含「算命/吉凶/宜忌/运势/改运」等词，末尾固定免责。
- **排盘详情隐藏**：完整盘面数据不下发到普通用户可见界面，仅存服务端，供专业爱好者经彩蛋/APP 版查看。
