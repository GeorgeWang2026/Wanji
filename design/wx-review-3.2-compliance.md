# 微信审核 3.2 拒审整改方案（算命/算运势/付费取名）

## 1. 问题定性（先说结论）

微信《常见拒绝情形 3.2》把「算命、算卦、占卜、看相、测字、风水、起名/取名、算运势」列为**平台未允许内容**，属于一票否决，不是「表述不规范」。截图是「八字详情」界面，而本小程序的功能本质就是玄学测算：

- 页面级：`奇门遁甲`、`四柱八字`、`梅花易数`、`卦典`
- 对话级：`chat` 页用奇门/八字/梅花排盘「辅助判断」，`GUIDANCE_PROMPT` 明写「未做深度命理推演」「不承诺任何命理结论」

因此**单纯改几个词、或只隐藏入口，都治标不治本**。「隐藏入口再提交」本质是「隐瞒真实内容」，上线后一旦被抽检/用户投诉/二次审核，直接封号，风险高于收益。以下按合规程度给出三档方案。

## 2. 三档方案对比

| 方案 | 做法 | 合规度 | 风险/代价 |
|---|---|---|---|
| A 彻底下线玄学 | 移除玄学页面与排盘链路 | 最高 | 放弃核心产品 |
| B 转型传统文化/趣味参考 | 保留页面但去迷信化（文案+交互+付费+免责） | 中 | 工作量大，仍有误判风险 |
| C 仅隐藏入口（用户提及） | 服务端开关，审核关/上线开 | 最低 | 隐瞒内容，封号风险极高 |

## 3. 推荐方案 B：转型「传统文化研究 / 趣味参考」

### 3.1 去迷信化文案（全量替换，含后端提示词）

核心原则：**只讲文化/信息，不下「吉凶、宜忌、运势、走向、改运、消灾」等结论，不做付费取名/算命承诺。**

敏感词 → 替代词映射（示例）：

| 原文 | 建议替代 |
|---|---|
| 算命 / 算运势 / 测算 | 传统文化研究 / 信息查阅 |
| 四柱八字 / 八字详批 | 四柱历法信息展示 |
| 命理 / 命理推演 / 命理结论 | 传统文化解读 |
| 吉凶 / 宜忌 / 大运 / 旺衰 / 流年 | 历史纪年 / 干支信息（或直接删除该结论块）|
| 奇门遁甲 / 梅花易数（作为「决策」卖点） | 古籍知识 / 传统符号知识 |
| 卦典 | 古籍文献查阅 |
| 开始推算 | 开始查阅 |
| 深度解读 | 资料查阅 / 内容解读 |

### 3.2 付费合规

- 现状：`/credits/consume` 按「每次深度解读 1 积分」扣费，本质是「付费算命」，正是 3.2 最敏感的红线。
- 改法：付费对象从「测算结论」改为「知识内容查阅 / 会员订阅」，**不承诺任何结果或效果**；付费前弹窗明确「本服务为传统文化资料整理，仅供研究参考」。

### 3.3 免责声明（必加，多处）

- 首页、结果页、付费确认弹窗、分享卡片均需出现：
  > 本内容基于公开传统文化资料整理，仅供学习研究与娱乐参考，不构成任何投资、医疗、婚恋、法律等决策建议。

### 3.4 类目与资质

- 玄学/算命无合规服务类目，若继续保留「预测类」功能，无法选到正确类目，仍会被拒。建议核对当前服务类目，向「文化/教育/工具」靠拢并如实描述。

  截图逐页核对: 无"吉凶/运势/宜忌"结论

## 6. 我的建议

1. **不要走「仅隐藏入口」**：成本低但封号风险不可控，等于把产品安全寄托在「不被抽检」上。
2. **优先选方案 B**：保留产品骨架，把「算命」降级成「传统文化资料查阅 + 趣味参考」，同步改文案、改付费口径、加免责声明；后端提示词也要一起改，否则线上仍会生成违规结论。
3. **若不愿大改，至少做「方案 B 的轻量版」**：下线付费测算入口、把「吉凶/宜忌/运势/大运/旺衰」等结论性内容全部删除，仅保留干支/历法信息展示 + 免责声明，先争取过审，再逐步调整。
4. **八字详情页是本次截图证据**，优先整改该页；其余玄学页同风险，不要只改一处。

以上为架构层建议，具体文案与「保留/删除哪些功能」需你拍板。确认方案后我再输出逐文件的整改实施清单交 Solo Coder 执行。
